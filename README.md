# Patent drawing assistant: demo site

The demo site for a prototype that answers questions about a US patent's drawings, citing the sentence in the description
and the spot on the drawing sheet each answer relies on, with every citation checked in code. Built by Shivaji Patil in
November 2026 with OCR (RapidOCR), OpenCV and Claude. The site: <https://shivaji-patil.github.io/patent-drawing-assistant-demo/>

This repository only hosts the built site. It is generated from the code repository, a private repository, by
`scripts/build_site.py`, and every result on the page is read from a results file there.
